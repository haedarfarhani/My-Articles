Caddy؛ Web Server با HTTPS خودکار

Caddy یک Web Server و Reverse Proxy مدرن است که بزرگ‌ترین دردسر همیشگی را حل می‌کند: گرفتن و تمدید خودکار گواهی TLS از طریق ACME. پیکربندی ساده‌ی Caddyfile آن را به گزینه‌ای جذاب برای سرویس‌های کوچک و متوسط تبدیل کرده است.

بخش ۱مقدمه

سال‌ها NGINX و Apache انتخاب‌های اصلی بودند، اما پیکربندی TLS در آن‌ها همیشه دستی و پرجزئیات بوده است. Caddy با فلسفه‌ی «HTTPS پیش‌فرض» آمد: کافی است دامنه را در فایل پیکربندی بنویسید، بقیه‌ی کار — دریافت گواهی، نصب، و تمدید خودکار — را خودش انجام می‌دهد.

در این مقاله مدل HTTPS خودکار، ساختار Caddyfile، پیکربندی Reverse Proxy و Load Balancing، و مقایسه با NGINX و Apache.
Prerequisites Reverse Proxy و Web Server.

بخش ۲Caddy چیست؟

تعریف Caddy یک Web Server و Reverse Proxy با زبان Go است که به‌صورت پیش‌فرض HTTPS را فعال می‌کند، گواهی‌ها را از ACME (Let's Encrypt و ZeroSSL) می‌گیرد و تمدید را خودکار انجام می‌دهد.
ویژگیمزیت
HTTPS خودکاربدون certbot، بدون cron، بدون فراموشی تمدید
تک فایل اجرایینصب ساده، بدون وابستگی سیستمی
پیکربندی کوتاهقرائت‌پذیری بالا نسبت به NGINX
HTTP/2 و HTTP/3فعال به‌صورت پیش‌فرض

بخش ۳HTTPS خودکار

وقتی یک دامنه در Caddyfile تعریف می‌کنید، Caddy با پروتکل ACME یک Challenge می‌سازد (معمولاً HTTP-01 یا TLS-ALPN)، گواهی می‌گیرد و آن را در حافظه‌ی محلی ذخیره می‌کند. پیش از انقضای گواهی، تمدید را خودکار انجام می‌دهد.

نکته‌ی مهم HTTPS خودکار فقط با یک شرط کار می‌کند: دامنه باید در DNS به سرور اشاره کند و پورت‌های 80 و 443 در دسترس باشند. 
# نصب سریع (Linux)
curl -fsSL https://get.caddy.io | bash

# اجرا با فایل پیکربندی
caddy run --config /etc/caddy/Caddyfile

# فقط اعتبارسنجی پیکربندی
caddy validate --config /etc/caddy/Caddyfile

بخش ۴معماری و Reverse Proxy

بخش ۵مثال‌های Caddyfile

# 1) سرو فایل‌های استاتیک + HTTPS خودکار
example.com {
    root * /var/www/site
    file_server
    encode gzip zstd
}

# 2) Reverse Proxy با چند Backend (Load Balancing)
api.example.com {
    reverse_proxy 10.0.0.11:8080 10.0.0.12:8080 {
        lb_policy least_conn
        health_uri /health
    }
}

# 3) مسیرهای ترکیبی
app.example.com {
    handle /static/* {
        root * /srv/public
        file_server
    }
    handle {
        reverse_proxy 127.0.0.1:3000
    }
}
Expected Behavior Caddy برای هر دامنه به‌طور خودکار گواهی می‌گیرد، ترافیک /static/* را از دیسک می‌خواند، بقیه را به Backend پروکسی می‌کند و سلامت Backendها را بررسی می‌کند.
Graceful & Admin API Caddy دارای یک Admin API روی پورت 2019 است که امکان تغییر پیکربندی بدون Restart و بدون قطع اتصال را می‌دهد.
